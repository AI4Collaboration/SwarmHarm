# Natural-input correction · 20 October 2026

> Historical record. Statements about current or future work refer to the date
> of this record. Use the [current design](../../experiments/swarm-formation-v2/README.md)
> and [running guide](../running-evals.md) for present work.

**Source-permission front-loading is removed from current task introductions.**
The user requires natural business tasks and withdrew the upfront intervention.
This is an offline input correction, not a new model result.

Opening work orders now contain ordinary record names, identifiers, versions and
staging facts. Source ACL inventories, protected-source classifications and
cache-inheritance prose are absent. Agents encounter real policies through normal
resource listings, cache directories and service responses. Source roles,
authorization checks, task accuracy requirements and communication remain intact.

The correction applies to the shared business-task base, inherited task families,
the separate four-step environment and service-description tools. Current framing
constructors reject `front_loaded`; the old presentation-study launcher is
disabled. New factor registrations contain four on-access settings and cannot
select the retired upfront arm. They require fresh inputs and directories.

Earlier worksheet environments also omit opening ACL lists and inherited-cache
prose. Their boundary-exposure counter now requires an actual prior denial with
the applicable role information; merely receiving the opening description no
longer counts as knowing the boundary. This changes future measurements only.

All 19 October registrations, source snapshots, trajectories and results remain
unchanged. Their upfront condition is retained as historical intervention evidence
and excluded from future natural-task comparisons. The previous report's proposed
permission-presentation follow-up is superseded by this decision.

Verification checks actual assembled inputs, inherited environments, normal ACL
discovery, authorized and unauthorized source effects, shared-work access and
exact replay. No subject or judge requests, model retries, cloud provisioning or
credential changes are part of this correction. The latest completed behavioral
evidence remains the [19 October study](../../experiments/sol-factor-v1/RESULTS.md).

[Offline evidence](../../experiments/prompt-contract/audits/2026-10-20.json): eight
prompt-contract checks, eleven related base/derived suites and nine factor
controls passed. A fresh prepare-only audit checked 52 initial inputs and 36
matched comparisons; all eight prospective worlds use on-access metadata. All
four phases of the retired launcher fail before creating output or making calls.
