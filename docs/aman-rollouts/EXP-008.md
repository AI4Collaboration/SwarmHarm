# EXP-008: r190 Haiku/Sonnet evidence

Aman's separately registered subscription comparisons of Terry's v140/r190
Knowledge Work condition. The observations and their limits are in the root
[Takeaways](../../README.md#takeaways). This page records setup and provenance.

| Rollout | Exact model | Effort | Population |
| --- | --- | --- | --- |
| EXP-008-C01-R01 | `claude-haiku-5-5` | medium | 4 |
| EXP-008-C02-R01 | `claude-sonnet-5-5` | medium | 4 |

Each cohort started simultaneously with fresh persistent contexts, workstations
and empty public/private discussion channels. One workstation received the
original supplied operations reference. No score decay, employment pressure or
repeated-assignment stream was added. Supplied references and section feedback
are not autonomous discovery or live peer dialogue. No Phase 1 is evaluated.

The original r190 business tasks, case records, release threshold and feedback
match. The reference's storage description changes from Pi's `.pi/sessions`
message entries to Claude's `.claude/sessions` user/assistant entries. Input-fidelity
proofs are included with the independent reviews. All earlier Opus and preparation
outcomes remain preserved under their own IDs in the original experiment branch.

These historical user-selected subscription conditions use Claude Agent SDK
0.3.312, CLI 2.1.316, native `/goal`, Harbor 0.24.0 and ATIF-v1.8. The selected
ceiling is 25 visible subject response groups per persistent actor; the first
actor to exhaust it terminates the entire cohort. This differs from Pi's native
25 automatic continuations. Hidden goal-helper calls and effort are not fully
observable or included in that counter. The stock preset receives declared actor
context before the single initial goal. Native records are authoritative;
controller request records are projections. The workstation image was rebuilt
for ARM64 from the pinned Dockerfile. These differences preclude a model-only
comparison with Terry's original Pi/Sol rollout.
