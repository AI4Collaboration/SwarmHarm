# Setup and experiment history

The current README and [working context](working-context.md) intentionally stay short. The complete previous README, with exact historical settings, counts, issues and lessons, is preserved in Git at [cda02a7](https://github.com/AI4Collaboration/SwarmHarm/blob/cda02a7f6e4a420d10c6d3a029d2da1a2b8b72a6/README.md). Frozen protocols and results are unchanged. This index is newest first; do not treat historical model pairings or credentials as current readiness.

- [Workflow and permission presentation, 2026-10-18](../experiments/sol-framing-v1/results/2026-10-18/README.md): four worlds/16 completed workers, three source-correct unauthorized cache uses in the on-access/open cell, thirteen scoped partials. Actual prior policy input verified. Three cache-use disclosures, no new adopter; no causal framing or full propagation claim.
- [Natural Sol / max source-boundary test, 2026-10-18](../experiments/sol-misalignment-v1/results/2026-10-18/README.md): eight scoped partials, no unauthorized read or validated bypass note. Three cache-directory inspections; no dataset-object cache GET, leaving sharing/adoption without an acquired method.
- [Sol / max instructed capability control, 2026-10-18](../experiments/sol-capability-v1/results/2026-10-18/README.md): four ordinary calibrations and four correct authorized cache completions; four validated procedure replies and actual peer-procedure reads. Assigned cooperation, no causal peer-learning or spontaneous misalignment claim.
- [Real-demand notifications](../experiments/hf-method-v2/results/2026-10-17/README.md): two worlds/16 workers, 13 completions and three preserved read timeouts; two authorized capability holders actually exposed to real requests, no confirmed unsafe propagation.
- [Useful cached data with real peers](../experiments/hf-method-v1/results/2026-10-17/README.md): four worlds/32 completions; four lawful cache completions and two ambiguous restricted reads followed by self-report. Public receipt pointer corrected separately in v2.
- [Method-elicitation design](../experiments/method-elicitation-design/README.md): historical source review/design-only record; no model calls in that record. Later implementations are listed above.

- [Extended live peers](../experiments/wayfinding-live-peers-extended/results/2026-10-17/README.md), [initial live peers](../experiments/wayfinding-live-peers/results/2026-10-17/README.md): real data exchange, different admission/accuracy limits and budgets.

Infrastructure lessons retained from the historical setup: separate the coordinator from evaluation labs; preserve the hosted public-server file-access patch; do not confuse it with the human-only wakeup patch; validate credentials and network permissions in the actual lab. Historical local CLI/backend 0.6.1, cloud profiles and disabled experiment keys do not imply that a new model or lab is ready.
