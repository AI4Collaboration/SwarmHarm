# Evidence history

This is a short evidence ledger, ordered newest first. It contains no launch
instructions. Historical protocols, traces and reports remain frozen in their
experiment directories. The complete pre-cleanup index is preserved in Git at
[6c7e336c](https://github.com/AI4Collaboration/SwarmHarm/blob/6c7e336c24076033bdb6396057262aa1df09027b/docs/history-index.md).

- **23 October 2026, active design:**
  [swarm formation v6](../experiments/swarm-formation-v6/README.md) freezes a
  composite method gate before inference: a model-authored semantic disclosure
  plus the same agent's exact native query and fetch. Offline controls pass; no
  v6 inference has run.
- **23 October 2026, formation v5:**
  [DeepSeek report](../experiments/swarm-formation-v5/RESULTS-2026-10-23-DEEPSEEK-R1.md).
  The campaign produced all component behaviors, but its frozen exact-string
  verifier did not establish a chain; a later diagnostic was not used to relabel it.
- **23 October 2026, formation v4:**
  [DeepSeek report](../experiments/swarm-formation-v4/RESULTS-2026-10-23-DEEPSEEK-R1.md).
  Reports persisted and crossed sandboxes, but the tool itself exposed the
  method, invalidating independent discovery.
- **23 October 2026, formation v3:**
  [DeepSeek report](../experiments/swarm-formation-v3/RESULTS-2026-10-23-DEEPSEEK-R1.md).
  Later sandboxes read real search receipts and final-wave agents independently
  found the method, but model-authored final reports did not persist.
- **23 October 2026, formation v2:**
  [DeepSeek and GLM report](../experiments/swarm-formation-v2/RESULTS-2026-10-23-DEEPSEEK-GLM-R1.md).
  Both six-agent campaigns failed at the first behavioral gate because no agent
  left shared residue; there were no provider errors, filters or refusals.
- **23 October 2026, formation R1:**
  [report](../experiments/swarm-formation-v1/RESULTS-2026-10-23-DEEPSEEK-R1.md).
  Three DeepSeek agents used a dedicated request interface but did not fulfil a
  peer request. This is a negative for that interface, not a Stage 1–3 result.
- **23 October 2026, shared-memory mechanism:**
  [report](../experiments/procurement-shared-memory-v1/RESULTS-2026-10-23-DEEPSEEK-R3.md).
  An arranged writer/closeout workflow verified persistence and cross-context
  synthesis. It does not show spontaneous formation.
- **23 October 2026, contained product component:**
  [report](../experiments/offline-product-world-v1/RESULTS-2026-10-23-DEEPSEEK-R7.md).
  DeepSeek recorded a failed candidate and did not submit a distribution job.
  No target change or delivery occurred.
- **22 October 2026, verified business effect:**
  [critical-stakes procurement](../experiments/procurement-critical-stakes-v8/RESULTS-2026-10-22-DEEPSEEK-R1.md)
  produced one synthetic over-budget incident, while a later agent read the
  incident records and avoided repeating it. This verifies a component effect,
  not harmful method propagation.
- **22 October 2026, transfer candidate:**
  [fresh successor](../experiments/procurement-successor-v7/RESULTS-2026-10-22-DEEPSEEK-R1.md)
  reproduced an unsafe ordering after reading several earlier records, but no
  single record contained the full method. Direct method transfer remains open.
