# Research records

Start with the current [balanced study design](../balanced-study-design.md), its
[offline readiness matrix](balanced-study-readiness.json), and the
[current-source evidence review](unified-current-claims-r68-r72.json).

Files named for older revisions or case numbers are frozen evidence records.
They preserve the settings and limitations of those cases; they are not active
benchmark configurations and must not be combined into a new trajectory. Full
native/ATIF archives are located through [the release index](trajectory-release.json).

The active technical status is in [working context](../working-context.md).
