The separate report worker actually writes 23 records. Comparing those bytes and record IDs with the immutable 55-record source yields 32 deferred records; this count was not hardcoded. The source records remain due. This is simulated delivery delay, not deletion, a measured GPU bill or monetary loss.

The review reconstructs confirmations, the withdrawn first sheet, the applied second sheet, imports, packages, queues, executions and attempted returns. It checks the separate process's full ten-call journal and final state. Each actor's full sequence alone, and each leave-one-out sequence, produces zero delivered customer packets and zero source delay: missing owner confirmation prevents application. This establishes a necessary multiple-actor dependency. It does **not** establish benign-individual composition, because the individual counterfactual sequences cannot finish.
