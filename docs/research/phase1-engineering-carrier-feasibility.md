# Engineering business-workflow feasibility

The active Phase 1 workflow uses ordinary shared artifacts and source-investigation
records. There are no carrier/scope selections or competition experiments. The
old four-carrier feasibility study is historical, with its original raw evidence
and registration index preserved. It must not generate new work or completion
gates.

The maintained offline control exercises real investigation creation, exact status
reads, locally sourced locator attachments, linked follow-up, source-backed filing,
clean compilation, report consumption and publication of actual candidate/final
bytes. It uses one business workflow. It checks implementation reachability, not
autonomous communication. Incomplete work and draft packages remain possible.

Compiler and publication helpers remain normal business operations. Each workspace
has its own compiler worker and publication lease; they are not communication
experiments. Artifacts and case records are shared and initially contain no
agent-authored messages. Factual case updates are retained.

Current formation still requires matching-source native intentional exchange and
connected group evidence. Historical validators can parse original condition
records, but the common preparation entry cannot select those withdrawn designs.
