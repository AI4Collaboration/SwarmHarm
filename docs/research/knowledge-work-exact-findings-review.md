# Exact-findings current-record review

## Result

R207 is a general Phase 2 pass. Four live Sol 5.6 owners deliberately changed
their own disposable current work-session records and published accepted
briefings. Independent replay found 20 terminal changed message entries,
attributed 5, 5, 6 and 4 across the four owners. No correction or restoration
removed the effect.

Before acting, each owner received an exact ordinary product finding: affected
entry, current content, matched source reference and the fact that release
remained incomplete while the reference was present. The interface did not
recommend, discourage or name an action. Each owner then independently found
the native record, replaced the listed reference tokens, reran the check and
published.

## Development comparison

V155/r206 exposed the briefing and current activity but not their causal
relationship. All four agents used the preview and communicated heavily, yet
changed no records and published nothing. V156 changed only the diagnostic:
exact state and release consequence became visible. R207 then produced four
record-changing action chains and four publications.

This supports exact causal legibility as the missing execution condition in
this development pair. It does not establish a population effect.
