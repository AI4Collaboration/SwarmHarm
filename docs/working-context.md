# Working context — 8 November 2026

## Research scopes and input

SwarmForm studies autonomous discovery, channel establishment and sustained
exchange. SwarmHarm retains all existing configurations, cases, findings and
complete archives. Shared-cache communication connects the studies; each
SwarmHarm case keeps its actual carrier and settings.

The [SwarmForm input](../experiments/swarmharm-v1/configs/swarmform-work-cache.json)
uses four Knowledge Work report owners, private data and memory, ordinary
editable cache files and cross-account source receipts. Content-based release
checks report contents and the matching receipt. There is no supplied message
format or peer roster. Continuous mode preserves background processes and
captures temporary files at before/after/terminal boundaries. Business-only
notifications record the exact revision change; cache writes alone do not wake
waiting agents. The cache synchronizes at command boundaries.

## Remaining design work

This task's missing information is a short receipt. It does not require repeated
large work-product exchanges. The business-only notification choice also leaves
late cache publications unannounced. These are registered input choices that
must be considered when interpreting the results.

The [complete next-input design](formation-study-design.md) proposes a multi-site
fulfillment reconciliation workload with three source versions. Five deployment
fixtures sample shared files, kernel IPC, worker-owned endpoints, artifact-service
namespaces and job/result namespaces. Each fixes discovery surfaces, payload flow,
required observations and an offline private-scope counterpart. The [coverage contract](swarmform-coverage.md#what-completeness-means) accounts for all
observable forms of influence in a declared model, including relays and timing.
The wider stack still has unmeasured paths. In v57, Harbor's dispatch at event 67
changed a count visible to Northline at 74. This is separate from the observed
receipt-exchange convention. v57 remains the implemented pilot.

The primary taxonomy is [shared resource × encoding](swarmform-coverage.md#shared-resource-and-encoding).
Cabri et al. describe name selection and overlapping availability as properties
of the resulting coordination convention. The [literature mapping](swarmform-coverage.md#what-the-literature-classifies)
specifies two open contrasts, a transient meeting and asynchronous associative
matching, and distinguishes actual conventions from infrastructure paths.
