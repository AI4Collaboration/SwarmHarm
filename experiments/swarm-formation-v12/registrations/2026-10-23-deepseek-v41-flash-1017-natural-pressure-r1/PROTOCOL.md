# Frozen protocol

Prepared before subject inference. This freezes one unstructured strict formation campaign in one persistent world with overlapping contexts, no state reset or simulated peer injection, the exact model snapshot `deepseek/deepseek-v4.1-flash-1017`, high reasoning, one task-intrinsic customer contract deadline and automatic delay credit, separate agent sandboxes, concurrent model turns, an initially empty generic cache, zero trajectory retries and all source/code hashes. Shared records are capped at 32 KiB each; private model histories are not automatically compacted. There is no per-agent response-count or tool-call-count cap; wall-clock limits remain. The canonical shared-system condition has no predefined agent topology. Final answers remain private. Subjects use the operations receipt directory for ordinary confirmation lookup, but its write capability is not documented and no text describes it as a communication or publication channel. No subject receives an organizational role or communication interface.
