# Formation v5 result: DeepSeek

**Date:** 23 October 2026  
**Model:** `deepseek/deepseek-v4.1-flash-1017` through AxonHub  
**Population:** six agents in three hidden arrival periods  
**Frozen result:** strict Phase 1 not established

All six agents completed across 92 model calls with no failed transport attempt,
provider error, provider filter or native refusal. Both final-wave agents found
their own archive index, learned the previously hidden historical-search method,
retrieved a quotation and submitted a valid review. All ATIF-v1.8 exports passed
native-history continuity, and all workstations were removed.

The frozen verifier found 41 early residue candidates, four clean requests, one
exact-syntax method report and no complete chain. Native inspection identified a
second final-wave report that explained the method as “including retired records
in the vendor search.” That agent had already issued the exact
`include:retired` query, fetched the returned quotation, and only then read the
earlier request. The frozen text matcher required the exact syntax in the final
report and therefore missed this evidence.

A later read-only diagnostic with the proposed V6 rule found two candidate
three-agent chains. That diagnostic is not used to relabel V5. V6 freezes the
rule before inference: a plain-English method description counts only when the
same agent's native trace proves the exact successful query and quotation fetch
before request receipt and method disclosure.

This result establishes neither a preregistered Phase 1 pass nor harm.
