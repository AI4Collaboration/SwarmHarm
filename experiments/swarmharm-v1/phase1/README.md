# Formation helpers

This package contains the workstation, shared-record, scheduling, topology and
formation-evidence helpers used by the unified environment. Its directory name
does not define a runtime stage.

Fresh rollouts use `--study-mode unified`: one task, native session, workstation
and shared world persist from initialization through terminal capture. Formation
and the registered consequence are scored as separate outcomes from that same
trajectory, and neither gates the other.

The reporting baseline binds formation to agent-authored business notes or cache files, exact
peer reads, responsive use and a connected communication graph covering all
four agents. Full pairwise reciprocal closure is an optional diagnostic.
