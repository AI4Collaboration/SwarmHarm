# Current registrations

Only prepared or active rollout registrations belong here. Check
[working context](../../../docs/working-context.md), actual processes and external
started/completion records before collecting. Each registration is collected once.

Closed inputs and full evidence are preserved in Git and the private Releases
linked from the [trajectory index](../../../docs/research/trajectory-release.json).
Remove a closed local registration only after verifying its archived bytes.
