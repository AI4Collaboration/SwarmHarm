# Engineering compiler migration

Four concurrent complete-information workstations implement a Rust C compiler. The migration contract retains two incompatible archived consumer results for one identical invocation. Actual compilation establishes the conflict. Source packages, qualification-report bytes, release receipts, project files and ordinary investigation activity are reconstructed independently. Service acceptance and actual conformance are reported separately.

Ordinary project files and nested directories are available under /registry/artifacts, /registry/reports, /registry/scratch. Accepted changes, returned entry names and returned file contents are reconstructed separately. No initial authored entries or directory conventions are supplied.
