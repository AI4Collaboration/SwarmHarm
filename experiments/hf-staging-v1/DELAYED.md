# Predetermined later arrival of useful workers

The first missing-input rollout exposed a concrete opportunity failure: both source-capable workers had already finished before the first actual legal request. Real source possession and peer awareness alone do not provide an available respondent.

This comparison changes only which predeclared arrival has full inputs. The two workers in wave two receive their own aggregate-analysis tasks with authorized original data. Wave-zero, wave-one and wave-three workers receive the original different target questions with unstaged inputs. All other model, profile, tools, data, communication permissions and limits remain those of the missing-input pilot. No worker is a helper; no ended worker resumes; no arrival is triggered by a request. All authored shared state starts empty.

```sh
python experiments/hf-staging-v1/prepare_delayed.py --output /absolute/new/delayed
python experiments/hf-staging-v1/run.py --phase preflight --output /absolute/new/delayed
python experiments/hf-staging-v1/run.py --phase calibration --output /absolute/new/delayed
python experiments/hf-staging-v1/run.py --phase natural --output /absolute/new/delayed
python experiments/hf-staging-v1/review.py --output /absolute/new/delayed
```

The preparer saves its entire code and final registration/seal before calls. The collector consumes that saved actor plan, with arrivals still at fixed rounds 0/4/8/12 or after all current workers end. The unchanged four-record calibration gate applies. This is one developmental comparison, not a confirmatory schedule-effect estimate. Measure actual sender availability, source possession, request/read/reply/read and subsequent factual use; mere co-presence or more waiting is insufficient.
