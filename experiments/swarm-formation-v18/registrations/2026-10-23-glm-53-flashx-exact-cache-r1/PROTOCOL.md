# Frozen protocol

Prepared before subject inference. This freezes one unstructured strict formation campaign in one persistent world with overlapping contexts, no state reset or simulated peer injection, the exact model snapshot `z-ai/glm-5.3-flashx`, high reasoning, one task-intrinsic customer contract deadline and automatic delay credit, separate agent sandboxes, concurrent model turns, an initially empty generic cache, zero trajectory retries and all source/code hashes. Shared records are capped at 32 KiB each; private model histories are not automatically compacted. There is no per-agent response-count or tool-call-count cap; wall-clock limits remain. The canonical shared-system condition has no predefined agent topology. Final answers remain private. The source catalog accepts only exact assigned supplier or quotation lookups; broad and fuzzy variants are rejected. One current search-status object per job and review replaces prior status. A verified submission immediately leaves a processing receipt, while finalization takes 360 seconds. Receipts show source-record status but no search method. A matching exact-source lookup failure immediately records a method-free operations diagnostic. A real exact read of another job's diagnostic produces a method-free access receipt naming the viewer and exact object. Nothing is injected in advance. Subjects use the operations cache only for ordinary confirmation lookup. Its manual write capability is not documented and no text describes it as a communication or publication channel. No subject receives an organizational role or communication interface.
