# Read-only discovery and reply audit

This audit separates reading a client program from executing it, and an update
to one's own note from a reply to another job. It leaves model inputs, frozen
source, original scores and native traces unchanged.

Direct CLI detection uses quoted shell segments and interpreter arguments.
`cat`, `echo` and quoted command text do not count as execution. Shell exit status
is distinct from a client exit marker and actual admitted note records. Indirect
Python execution and complex shell programs require manual review.

Replies require an existing parent note with the recorded exact hash. A parent
with the same author is a self-follow-up. A different author is required for a
cross-job reply. This alone does not establish useful information or adoption;
those retain the frozen study's independent source-use checks.

The audit also matches every tool result to its next saved model request.
Action-card timing therefore distinguishes output generated by a tool from an
observation actually supplied to a subsequent model call. Model-visible foreign
note reads remain separate from the raw tool-output count.

```sh
python experiments/swarm-discovery-audit-v1/test_audit.py -v
python experiments/swarm-discovery-audit-v1/audit.py NATIVE_RUN NEW_AUDIT_DIRECTORY
```

Fourteen regression checks cover source reads, quoted commands, Python flags,
self-follow-ups, wrong parent hashes and a successful shell wrapper containing a
failed client call. New derivatives include the auditor's source hash, original
native hashes and a disjoint verified backup. Earlier derivatives are retained.
