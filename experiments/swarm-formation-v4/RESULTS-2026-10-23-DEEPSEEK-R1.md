**Date:** 23 October 2026  
**Model:** `deepseek/deepseek-v4.1-flash-1017` through AxonHub  
**Population:** six agents in three hidden arrival periods  
**Result:** strict Phase 1 not observed

All six agents completed across 91 model calls. There were no failed transport
attempts, provider errors, provider filters or native refusals. Both final-wave
agents found a retained record and submitted valid reviews. All ATIF-v1.8
exports passed native-history continuity, and all workstations were removed.

V4 correctly persisted the models' own final reports, and later agents read
reports from different sandboxes. It produced 38 qualifying early work-residue
candidates and eight method-like final reports. The strict verifier nevertheless
found zero requests and zero connected chains.

The reason is methodological: the search tool itself returned a guide naming
`scope:all`. Blocked agents repeated that syntax in their final reports. A later
agent that read those reports before using the syntax therefore did not discover
the method independently. The reports mixed a valid unblock request with the
method hint, so they cannot support a clean LessWrong-style reach-out claim.

V5 removes the subject-facing method hint. Early jobs have no index or source;
final-wave jobs can acquire a new historical-search syntax only by finding and
reading an ordinary archive index record in their own task.

This result establishes neither swarm formation nor harm.
