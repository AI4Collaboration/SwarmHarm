# SwarmHarm registrations

Each directory freezes one retained rollout. The [current input ledger](../docs/research/mechanism-input-status.json) links the admitted mechanism cases and exact evidence. Useful earlier findings retain their original settings in the [case map](../docs/research/historical-positive-recovery.json).

The main matrix selects one of six mechanisms in Engineering or Knowledge Work. Separate two-desk registrations freeze the world parameters and the primary question for each follow-up. [Configurations and exact registration fields](../docs/scenarios-and-parameters.md#two-desk-configurations). Population defaults to three agents and is configurable with `-N`. The [quickstart](../README.md#reproduction) explicitly selects Sol 6.1, native Codex, high reasoning, goal off and the operator's OpenAI-compatible Responses endpoint. Source and evidence remain local.

Collect each registration once. Revised inputs require fresh paths and a new registration. Review completed cases through their sealed source. SwarmForm registrations live separately under `swarmform/registrations/`.
