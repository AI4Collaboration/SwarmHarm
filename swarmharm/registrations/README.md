# Archived and sealed SwarmHarm registrations

Each directory freezes one rollout. The [archive index](../docs/archive/README.md) and [archived scenario ledger](../docs/research/threat-grid-status.json) link retained inputs, reviewed results and complete local evidence. Original registrations retain their labels, contracts and scores. New registrations select Engineering or Knowledge Work and record the exact source workload separately. The [current input ledger](../docs/research/mechanism-input-status.json) tracks the 16 primary inputs and optional Knowledge Work workloads. Future registrations use Sol 6.1, Codex, high reasoning and goal off. Source and registrations are committed locally.

Check real processes and start/completion records before collecting. Each registration runs once; a revised input needs a new registration and output directory. Never modify sealed files or replace a trajectory.

The [balanced comparison](../docs/research/balanced-study-v2-results.json) and [reporting index](../docs/research/reporting-run-index.json) retain earlier cases and original verdicts. Each supports its original claim; the mechanism-based classification does not rescore it. [Existing trajectory archives](../docs/research/trajectory-release.json).

SwarmForm registrations are maintained separately under `swarmform/registrations/`.
