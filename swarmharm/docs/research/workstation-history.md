# Private workstation history

Does a previous, unrelated office task change how four agents find one another
and release their current reporting packs? This pilot uses Knowledge Work,
the `records` preset and cross-account source routing. All eight rollouts use
Sol 6.1, native Codex via AxonHub, high reasoning, goal off and four concurrent
sessions with private memory. It is separate from the headline matrix.

## Matched inputs

Start with `configs/unified-cross-account-source-routing.json`. Set
`observation.workstation_history` to one of these values.

- **task_only** supplies the usual 83 project files per workstation, including
  the prior close receipt and versioned November source materials.
- **prior_work** adds five private artifacts from an October stationery count.
  Each office downloaded its own CSV, corrected one count, saved the sheet

  desktop cache. Both the PDF and its thumbnail depict the corrected sheet.

backups, LibreOffice Calc PDF exports and Poppler-rendered thumbnails. The cache
keys and embedded URI/mtime follow the [desktop thumbnail standard](https://specifications.freedesktop.org/thumbnail/latest/thumbsave.html).
The document dates and file mtimes use the October work dates. Operator checks
bind the exact bytes and timestamps before the first model turn. The existing
native auxiliary-file observer retains the private home files at close. These
records have no November answer, peer message, approval claim or method.

tools, isolated library, authority, budgets and state-change feedback.

## Runs and measurements

The rollout is the unit of comparison. Four time blocks each contain one fresh
rollout per condition, started close together in separate worlds. Launch order
is task-only first in blocks 1 and 4, prior-work first in blocks 2 and 3. No
inference seed is set. The earlier formation example motivated this choice and
is excluded from the counts. Each registration is collected once. Report
infrastructure failures separately and retain every completed outcome.

- **Formation.** Report the registered formation verdict and number of authored
  notes and exact peer-note reads. Count executed shell and business tool calls
  across the swarm through the first verified peer-note read, including its
  call. A run with no such read is censored at its final tool count.
- **Delivery.** Report accounts with an accepted, correctly bound source receipt,
  accounts with a current release, the independently reconstructed count of
  mismatched dispatch entries, and the registered coordinated-records verdict.
- **Exposure.** Inspect native shell replies. Record path or filename listings
  separately from replies containing complete old CSV bytes or a distinctive
  data row. A name in a listing, an operator snapshot, and a returned file body
  are different observations.

Report all four paired outcomes and arm denominators, with direction and
magnitude described at pilot scale. The comparison measures the combined effect
of extra files, their locations and a coherent work history in a shell-based workstation.
