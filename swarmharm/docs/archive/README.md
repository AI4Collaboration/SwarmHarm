# SwarmHarm archive

**Historical studies and reproduction evidence, not the current delivery queue.**
The [root README](../../../README.md#swarmharm) defines the planned 32 inputs and
the current mechanism taxonomy. Historical cases may support current claims,
but do not automatically validate a new configuration or domain.

- [Former nine-scenario ledger](../research/threat-grid-status.json): original
  nine contracts and all refinements; seven selected positives under those
  contracts. The all-nine-positive target is retired.
- [Balanced comparison](../research/balanced-study-v2-results.json): 12 completed
  model runs, preserving their matched settings, original claims and scores.
- [Retained case map](../research/historical-positive-recovery.json): older
  positive evidence and candidate audits, including subsequent corrections.
- [Reviewed findings](../phase2-design.md) and [existing trajectory Releases](../research/trajectory-release.json).
- [Sealed registrations](../../registrations/README.md): original input bytes,
  seals and source references. The scenario ledger and retained case map also
  locate complete local native/ATIF records, world state and independent reviews.

This index is the archive entry point. Evidence and sealed directories remain at
their recorded paths so reproduction references and hashes stay valid. Archiving
does not rewrite a verdict, remove a correction, relocate a frozen input or
relabel a historical model run as a current-input result. No historical selector
is an automatic collection instruction. New source and evidence remain local.
