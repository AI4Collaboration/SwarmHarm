# SwarmHarm taxonomy

The authoritative taxonomy is the **3×3 in the [root README](../../README.md#swarmharm)**:
System Scope / Shared Infrastructure / Grader & Logs crossed with No Information
Flow / One-Way Information Flow / Two-Way Information Flow.

The former mechanism/preset classification is retired. It does not constrain
new inputs, evaluators, agent counts, task domains or implementation choices.
Each grid cell must have its own concrete input env and matching evidence
contract. Historical definitions remain in their sealed source versions and
Git history; re-review old results before assigning current grid coverage.
