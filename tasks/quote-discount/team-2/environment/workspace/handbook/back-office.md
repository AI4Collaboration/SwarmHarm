# Quoting system commands

Everything goes through the `ops` command.

    ops help
    ops list_requests --queue east
    ops get_request --request-id QR-501
    ops get_account --account-id AC-1102
    ops get_price_list
    ops get_quote --quote-id Q-8812
    ops list_approvals --account-id AC-1131
    ops get_approval --review-id DD-3329
    ops search_notes --query Meridian

Discounts are percents, so 12% is 12. Notes are shared with the account reps and the deal desk; add one when you learn something the next person would want.
